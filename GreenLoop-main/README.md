# GreenLoop

**ส่งต่อเทคโนโลยี เพื่อโลกที่ยั่งยืน** — Powered by GreenDigital

แพลตฟอร์มซื้อขาย-ส่งต่ออุปกรณ์ดิจิทัลมือสอง สินค้าดิจิทัล และระบบรีไซเคิลอุปกรณ์อิเล็กทรอนิกส์ (E-Waste) พร้อมระบบ Green Point

เทคโนโลยี: PHP 7.3+ · MySQL / MariaDB · HTML5 · CSS3 · JavaScript · Bootstrap 5 (ทำงานบน XAMPP)

## การติดตั้ง (XAMPP)

1. คัดลอกโฟลเดอร์นี้ไปไว้ที่ `C:\xampp\htdocs\GreenLoop`
2. เปิด Apache และ MySQL ใน XAMPP Control Panel
3. เปิด phpMyAdmin → Import → เลือกไฟล์ `database.sql` (ไฟล์จะสร้างฐานข้อมูล `greenloop` พร้อมข้อมูลตัวอย่าง)
4. หากฐานข้อมูลไม่ได้ใช้ `root` / ไม่มีรหัสผ่าน ให้แก้ค่าใน `config.php`
5. เปิด `http://localhost/GreenLoop/`

ทางเลือกสำหรับทดสอบโดยไม่ใช้ Apache: `php -S localhost:8000` ในโฟลเดอร์โปรเจกต์
(โหมดนี้ไม่อ่านไฟล์ `.htaccess` จึงใช้สำหรับพัฒนาเท่านั้น)

Bootstrap, Bootstrap Icons และฟอนต์ Prompt โหลดจาก CDN จึงต้องเชื่อมต่ออินเทอร์เน็ต

## กติกาของระบบ

**การได้รับ Green Point**

| กิจกรรม | คะแนน |
| --- | --- |
| ขายสินค้ามือสองสำเร็จ | +20 |
| ซื้อสินค้ามือสองสำเร็จ | +10 |
| ส่งคำขอรีไซเคิล | +10 |
| รีไซเคิลสำเร็จ (แอดมินอนุมัติ) | +50 |
| ขาย Digital Product | +5 |
| ซื้อ Digital Product | +5 |

**การใช้ Green Point** — ส่วนลดตอนชำระเงิน (10 คะแนน = ฿1 สูงสุด 20% ของราคา), ฟรีค่าธรรมเนียมการขาย, คูปองส่วนลด, ของรางวัล, อัปเกรด Premium

**ขั้นตอนคำสั่งซื้อ**

- สินค้ามือสอง: ผู้ซื้อชำระด้วย Wallet → ผู้ขายแจ้งจัดส่ง → ผู้ซื้อยืนยันรับสินค้า → ระบบโอนเงินให้ผู้ขาย (หักค่าธรรมเนียม) และแจกคะแนนทั้งสองฝ่าย
- สินค้าดิจิทัล: ชำระเงินแล้วสำเร็จทันที ดาวน์โหลดไฟล์ได้จากประวัติการซื้อ
- ยกเลิกคำสั่งซื้อ: คืนเงิน คะแนน คูปอง และสต็อกอัตโนมัติ

**ระบบสร้างรายได้** — ค่าธรรมเนียมการขาย 5% (Premium 3%), แบนเนอร์โฆษณา, สมาชิก Premium ฿99 / 30 วัน, โปรโมทสินค้า ฿29 / 7 วัน (ปรับได้ในหน้าตั้งค่าเว็บไซต์)

## โครงสร้างไฟล์

```
assets/             CSS และ JavaScript

```
